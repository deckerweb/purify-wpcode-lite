# Security reporting

[Deutsch](#deutsch)

Maintainer: [David Decker](https://github.com/deckerweb). Repository: [Purify WPCode Lite](https://github.com/deckerweb/purify-wpcode-lite).

Report vulnerabilities privately using [GitHub’s security advisory form](https://github.com/deckerweb/purify-wpcode-lite/security/advisories/new). Private Vulnerability Reporting is enabled. Do not publish vulnerability details in Issues or Discussions. Include the affected version, reproduction steps and impact; do not include passwords, tokens or personal site data.

The embedded Library and Updater use the host's confidential reporting route. There is no separate public email address. Security fixes are handled independently of routine maintenance; no response deadline is promised.

## Deutsch

Betreuer: [David Decker](https://github.com/deckerweb). Repository: [Purify WPCode Lite](https://github.com/deckerweb/purify-wpcode-lite).

Melde Sicherheitslücken vertraulich über [GitHubs Formular für Sicherheitsmeldungen](https://github.com/deckerweb/purify-wpcode-lite/security/advisories/new). Private Vulnerability Reporting ist aktiviert. Veröffentliche keine Details zu Sicherheitslücken in Issues oder Discussions. Nenne betroffene Version, Schritte zur Reproduktion und Auswirkungen. Keine Passwörter, Tokens oder persönlichen Website-Daten übermitteln.

Eingebettete Library und Updater verwenden den vertraulichen Meldeweg des Host-Plugins. Es gibt keine gesonderte öffentliche E-Mail-Adresse. Sicherheitskorrekturen werden unabhängig von regulärer Wartung behandelt; eine Antwortfrist wird nicht zugesagt.
